УСТАНОВКА (кратко)
------------------
1. Положить arena_of_nations-1.0.0.jar в mods/
2. Один раз: scripts\SETUP_LOCAL_OVERLAY_HTTPS.cmd
3. START_ARENA.cmd → открыть мир
4. OPEN_OVERLAY_WINDOW.cmd
5. TikTok LIVE Studio: захват окна + chroma #FF00FF
6. Настроить StreamToEarn по config\STREAMTOEARN_SETUP.md
