# TikTok / OBS Overlay — бесплатно, без домена

Ничего платить не нужно: ни домен, ни Cloudflare Tunnel, ни подписки.

## Что видно на стриме

Прозрачный вертикальный HUD (1080×1920):

- сверху: фаза боя + **сколько осталось до конца** + сколько стран;
- по бокам: страны (флаг + код), **бойцы в поле**, **резерв**, короткий статус;
- центр экрана свободен под картинку Minecraft.

## OBS (если пустой экран)

1. Minecraft с модом уже запущен (иначе `127.0.0.1:8766` не отвечает).
2. Источник **Браузер**, URL:

```text
http://127.0.0.1:8766/overlay/tiktok
```

3. **Ширина 1080**, **высота 1920**, FPS 30.
4. Снимите «Завершать исход, когда он не отображается».
5. ПКМ по источнику → **Обновить**.
6. Проверка: откройте тот же URL в Chrome.
   - Chrome пустой → Minecraft не отдаёт оверлей.
   - Chrome ок, OBS пустой → перезапустите OBS **не** от имени администратора (если игра обычная).
7. После обновления мода всегда жмите **Обновить** в OBS (кэш CEF).

Скопировать URL: `CopyLocalOverlayUrl.cmd`.

Данные стран появляются после входа в матч (`/arena_gift` / подарки), не от `/arena_team_duel`.
